# 登记表字段结构（6 分类 sheet）

> 来源：国网知识产权月度统计模板（2026-06 版实测提取）。**各类别字段结构不同，严禁合并成通用单列结构。**

## 1-国内专利-受理（50 列）

必填：部门/单位、序号、专利名称、专利类型、申请人、申请日期、申请号、使用保管人、发明/设计人、专利权人、上报年份、上报季度、技术领域(一~四级)、智能电网环节、知识产权增加方式、项目类型

```
部门/单位, 序号, 专利名称, 专利类型, 申请人, 申请日期, 申请号, 使用保管人, 发明/设计人,
专利权人, 完成单位, 申请单位, 专利权人与上报单位的关系, 上报年份, 上报季度,
技术领域(一级), 技术领域(二级), 技术领域(三级), 技术领域(四级), 智能电网环节,
知识产权增加方式, 项目类型, 项目编码, 项目名称（非本单位牵头申报，可填写"项目名称暂不掌握"）,
项目出资单位, 项目承担单位, 项目竣工验收时间, 项目工程预算, 竣工决算金额,
项目资本化金额, 项目费用化金额, 附属载体, 设备分类(一级), 设备分类(二级),
应用阶段(成熟度), 重要性, 获奖情况, 获奖年份, 国内市场前景, 国内市场前景说明,
国外市场前景, 国外市场前景说明, 产品名称及型号, 产品数量, 产品使用单位及地点,
产品备注, 相关标准名称, 标准文号, 标准性质, 相关标准条款内容
```

## 2-国内专利-授权（51 列）

= 受理 50 列 + **授权公告日**（插在"申请日期"与"申请号"之间）。必填同受理 + 授权公告日。

```
部门/单位, 序号, 专利名称, 专利类型, 申请人, 申请日期, 授权公告日, 申请号, 使用保管人,
发明/设计人, 专利权人, 完成单位, 申请单位, 专利权人与上报单位的关系, 上报年份, 上报季度,
技术领域(一级~四级), 智能电网环节, 知识产权增加方式, 项目类型, ...（其余同受理表）
```

## 3-海外专利PCT阶段（32 列）

必填：部门/单位、序号、专利名称、专利类型、申请人、国际申请号、国际申请日、使用保管人、专利权人、上报年份、上报季度、技术领域(一~四级)、智能电网环节、知识产权增加方式、项目类型

```
部门/单位, 序号, 专利名称, 专利类型, 申请人, 国际申请号, 国际检索报告日, 国际申请日,
使用保管人, 发明/设计人, 专利权人, 完成单位, 申请单位, 专利权人与上报单位的关系,
上报年份, 上报季度, 技术领域(一级~四级), 智能电网环节, 知识产权增加方式,
项目编码, 项目类型, 项目名称, 项目出资单位, 项目承担单位, 项目竣工验收时间,
项目工程预算, 竣工决算金额, 项目资本化金额, 项目费用化金额
```

## 4-论文（28 列）

必填参考：部门/单位、序号、论文名称、作者姓名、第一作者单位、刊物名称、刊号、刊期、刊物级别、上报年份、上报季度、技术领域(一~四级)、知识产权增加方式、项目类型

```
部门/单位, 序号, 论文名称, 作者姓名, 第一作者单位, 刊物名称, 刊号, 刊期, 刊物级别,
技术领域(一级~四级), 第一作者单位与上报单位的关系, 上报年份, 上报季度, 系统内排名, 备注,
项目编码, 项目类型, 项目名称, 项目出资单位, 项目承担单位, 项目竣工验收时间,
项目工程预算, 竣工决算金额, 项目资本化金额, 项目费用化金额
```

## 5-软著（31 列）

必填：部门/单位、序号、软件著作权名称、证书编号、使用保管人、技术领域(一~四级)、登记号、著作权人、登记日期、上报年份、上报季度、知识产权增加方式、项目类型。额外可填：权力获得方式（原始取得）、权力范围（全部权利）。**无"智能电网环节"列。**

```
部门/单位, 序号, 软件著作权名称, 证书编号, 使用保管人, 技术领域(一级~四级), 登记号,
申请人, 著作权人, 权力获得方式, 权力范围, 登记日期, 首次发表日期, 授权否,
著作权人与上报单位的关系, 上报年份, 上报季度, 知识产权增加方式, 项目编码, 项目类型,
项目名称, 项目出资单位, 项目承担单位, 项目竣工验收时间, 项目工程预算, 竣工决算金额,
项目资本化金额, 项目费用化金额
```

```
技术领域(一级~四级), 作者单位与上报单位的关系, 备注, 上报年份, 上报季度, 系统内排名,

项目工程预算, 竣工决算金额, 项目资本化金额, 项目费用化金额
```

## 证书/文件 → 字段映射

| 来源 | 提取字段 → 表字段 |
|---|---|
| 专利受理通知书 | 发明创造名称→专利名称；发明/实用新型→专利类型；申请号（带点格式如 202610995253.X）→申请号；申请日→申请日期；申请人→申请人/专利权人；发明人→发明/设计人（顿号）；申请方案卷号→（无对应列，可弃） |
| 专利授权证书 | 同上 + 授权公告日→授权公告日（Sheet2）；申请日时申请人→申请人；申请日时发明人→发明/设计人；专利号 ZL…→（无对应列） |
| 软著登记证书 | 软件名称+V1.0→软件著作权名称；软著登字第xx号→证书编号；20xxSRxxxxxx→登记号；著作权人→著作权人；登记日期→登记日期；权利取得方式/权利范围→对应列；首次发表日期：未发表→首次发表日期 |
| PCT 通知书 | 发明名称→专利名称；国际申请号（PCT/CNxxxx/xxxxxx）→国际申请号；国际申请日→国际申请日；申请人→申请人/专利权人 |

## 格式规范

- 多人列表（发明人/申请人/著作权人）一律中文顿号"、"分隔
- 日期统一 yyyy-mm-dd（证书上是"2026年07月06日"需转换）
- 申请号保留证书带点格式（202610995253.X）；软著登记号 20xxSRxxxxxx 原样
- 证书上没有的信息不留空不臆造
